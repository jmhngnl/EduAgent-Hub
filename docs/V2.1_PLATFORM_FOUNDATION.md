# EduAgent Hub V2.1 Platform Foundation

This patch is intentionally limited to the first V2.1 cut. It adds a deterministic Spring Boot business plane without rewriting the existing FastAPI/LangGraph runtime.

## Added services

- `mysql`: business source of truth for platform data.
- `platform-server`: Spring Boot 4.1.1 + Java 21 + MyBatis-Plus + Flyway.

Existing `api`, `worker`, `postgres`, `redis`, and `frontend` services remain in place.

## Business tables

Flyway creates:

- `conversation`
- `chat_message`

`chat_message` already reserves `task_route`, `skill_name`, `tool_calls_json`, `citations_json`, `token_usage_json`, and `latency_ms` for the next Java-to-Python streaming integration.

## API

```text
POST   /api/conversations
GET    /api/conversations?workspaceId=demo&limit=50
GET    /api/conversations/{id}
GET    /api/conversations/{id}/messages
POST   /api/conversations/{id}/messages
DELETE /api/conversations/{id}
```

The first USER message automatically changes a `New Chat` title to a compact title derived from the message.

## Deploy

From the repository root:

```bash
chmod +x scripts/redeploy-v2.1.sh
./scripts/redeploy-v2.1.sh
```

The script rebuilds and starts services without deleting named volumes.

Default endpoints:

```text
Frontend       http://localhost:5173
FastAPI        http://localhost:8000
Platform API   http://localhost:8081
Platform health http://localhost:8081/actuator/health
```

## Smoke test

Create a conversation:

```bash
curl -X POST http://localhost:8081/api/conversations \
  -H 'Content-Type: application/json' \
  -d '{"workspaceId":"demo"}'
```

Then use the returned `id`:

```bash
curl -X POST http://localhost:8081/api/conversations/<id>/messages \
  -H 'Content-Type: application/json' \
  -d '{"role":"USER","content":"Flow Matching 和 Diffusion 有什么区别？"}'

curl http://localhost:8081/api/conversations/<id>/messages
curl 'http://localhost:8081/api/conversations?workspaceId=demo&limit=50'
```

## Not included in this cut

The current web UI still talks to the existing FastAPI runtime. The next V2.1 cut should add the Java SSE proxy and then migrate the frontend to React history/sidebar against the platform API. RabbitMQ, MinIO, JWT/RBAC, A2A, and Kubernetes remain out of scope.
