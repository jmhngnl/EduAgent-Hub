# EduAgent Hub V2.1 Release

V2.1 closes the demo-to-product gap for the first usable platform milestone.

## Delivered

- React 19 research workspace
- Durable Conversation / ChatMessage history in MySQL
- Spring Boot platform/BFF boundary
- Java -> FastAPI -> LangGraph SSE proxy
- Route / Skill / Tool / Sources trace persistence
- Conversation refresh recovery and switching
- Document Center Lite
  - upload PDF / TXT / Markdown
  - paste text rules or notes
  - paper vs lab_document classification
  - Celery task status polling
  - indexed document list
  - retrieval verification search
- Browser traffic goes through Spring Boot; chat/document UI no longer calls FastAPI directly

## V2.1 document architecture

```text
React
  -> Spring Boot /api/documents*
  -> FastAPI /v1/knowledge/*
  -> Celery + Redis
  -> PostgreSQL + pgvector
```

This intentionally reuses the proven V1 ingestion runtime. V2.1 does not introduce MinIO or RabbitMQ yet.

## Deferred

- Agent-initiated knowledge writes
- User / Login / JWT / Refresh Token
- Workspace Membership / RBAC
- MinIO / RabbitMQ document lifecycle
- LangGraph Postgres Checkpointer / HITL
- Reranker / Eval / advanced observability

These belong to V2.2+ so V2.1 remains a stable product checkpoint instead of an over-scoped rewrite.

## Release acceptance

1. Existing conversations restore after refresh.
2. Chat streams through Spring Boot and persists USER + ASSISTANT.
3. Route / tools / sources restore from MySQL history.
4. Documents page lists existing indexed documents.
5. PDF/TXT/MD upload returns queued and reaches Celery SUCCESS.
6. Pasted text is synchronously indexed.
7. Retrieval check returns relevant chunks.
8. A newly indexed document can subsequently be used by Agent RAG.
9. FastAPI health, worker, MySQL, PostgreSQL and Redis remain healthy.
