# EduAgent Hub V2.1 Round 3 — React Product UI

Round 3 turns the V1 demo page into a durable conversation workspace.

## Browser architecture

```text
Browser :5173
  -> nginx /api/*
  -> Spring Boot platform-server :8080
  -> FastAPI /v1/chat/stream
  -> LangGraph
```

The browser no longer needs to know the FastAPI port or API key for chat.

## Product surface

- History sidebar backed by MySQL conversations
- New Chat and soft delete
- Conversation switching
- History recovery after refresh
- POST SSE streaming through Spring Boot
- Markdown assistant messages
- Agent Trace: route, skill, tools, latency
- Sources panel from persisted `citations_json`

## State split

- TanStack Query: server state (`conversations`, `messages`)
- Zustand: selected conversation and current stream trace
- MySQL: authoritative persistent history
- Redis: Python recent context only

## Citation provenance

The accompanying Python change stops treating generic prefetch chunks as final citations for remote-model runs. Citations emitted on `done` now come from tools actually invoked during that run, including Semantic Scholar paper search results.

## Acceptance

1. Open `http://<host>:5173`.
2. Create a conversation and send a question.
3. Observe streaming text and live Route/Tools.
4. Wait for Sources and latency on completion.
5. Refresh the browser: conversation and messages must recover.
6. Create a second conversation, then switch back to the first.
